## 為什麼這個時間去？

11 月底到 12 月中是寮國一年中**最舒適**的季節：

- **乾季、涼爽**：白天約 25–28°C，夜晚 15–18°C，濕度低，適合步行。
- **湄公河水位穩定**：適合搭船遊河、搭乘貢船前往北坎洞（Pak Ou Caves）。
- **關西瀑布（Kuang Si）水量充沛清澈**：乳藍色水池最美的時期。
- **國際航班艙位尚未進入聖誕高峰**：機票與飯店價格相對合理。

## 龍坡邦是什麼地方？

龍坡邦（Luang Prabang）是寮國舊都，坐落於**湄公河**與南康河（Nam Khan）交匯的半島上，1995 年被列入 **UNESCO 世界文化遺產**。城中保留 30 多座金頂佛寺、法式殖民建築、法國麵包店與寮式餐館，清晨有僧侶托缽（Tak Bat）儀式，傍晚有夜市與普西山日落，是東南亞最悠閒、最具文化底蘊的小城之一。
